Add Terraform helpers: a dashboard toolbar popover showing the `terraform import` command and provider setup for the ClickHouse Terraform provider's ClickStack resources, and a team settings section ("API & Agents") to download a Terraform import file covering dashboards, alerts, saved searches, sources, connections, and webhooks.

Both surfaces are import-only. Resource configuration is generated by `terraform plan -generate-config-out`, which reads through the provider, rather than by HyperDX — the external API's dashboard serialisation is a field allowlist, so generating `dashboard_json` from it could silently drop tile settings on apply.

Also redacts `Authorization` and `Cookie` headers from API request logs.
