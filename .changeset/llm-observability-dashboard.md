Add read-time, schema-agnostic LLM observability on top of existing trace and log data — no ingestion changes required, and it works retroactively on already-ingested telemetry. Spans instrumented with the OTel GenAI semantic conventions, OpenLLMetry, OpenInference, or the Vercel AI SDK gain an LLM tab in the span side panel rendering the normalized conversation (roles, markdown, tool calls) with a token-usage and cost summary, and the trace waterfall labels LLM spans with model and token count. A new `/llm` preset dashboard covers traffic, token split (uncached/cached/cache-write/output/reasoning), estimated cost by model (bundled price catalog with cache-read discounts and cache-write premiums; an instrumentation-provided cost attribute always wins), latency/TTFT, tool analytics, per-session timelines with lazy-loaded conversations, and side-by-side LLM span/log search. Aggregations elect an app's own cost-reporting spans as the authoritative per-call reporters so apps emitting several instrumentation dialects in parallel (e.g. opencode emitting OpenInference and Vercel AI spans for each call) are counted once — verified to match opencode's self-reported session cost exactly.
